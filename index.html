There is a saved session ().

Your data never leaves your computer. The file is read in your browser only, nothing is uploaded. Only the map tiles and the optional place search load data from the internet.

Map columns

Tell Herbie which column of your table holds which information. Known column names are detected automatically, no matter how they are written (upper or lower case, spaces, umlauts). Unmapped fields stay empty and can be filled in per specimen later. Fields marked * belong on every herbarium label and are strongly recommended, but none of them is required.

Own fields

Want more on the label? Add any other column of your table, e.g. a flower colour or a habitat, and choose the name that should be printed. Example: column col, name Colour prints "Colour: red". Only columns not used above can be chosen.
